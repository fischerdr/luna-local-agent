# Her sounds

Clips here play with her gestures. Not in git - bought or downloaded
sounds are yours to use, usually not yours to share.

- A gesture names a sound: `sound: 'touch-self'` plays `touch-self.mp3`
  (or .ogg, .wav, .m4a).
- A folder works too: `gasp/` full of clips, and `sound: 'gasp'` picks one
  at random each time. So do numbered files: `moan-sexy01.mp3`,
  `moan-sexy02.mp3`... all answer to `sound: 'moan-sexy'`.
- No file, no sound. Nothing breaks.
- `"portrait": {"sounds": false}` turns them all off; `"sound_volume": 0.8`.
